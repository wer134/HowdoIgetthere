# 엑셀 지도 만들기

여행 일정표 같은 엑셀을 올리면, **장소** 열에 적힌 이름을 구글 지도에서 찾아 지도에 핀을 꽂아 주는 웹앱입니다.
BatchGeo처럼 주소가 꼭 있어야 하는 방식이 아니라, 구글 지도 검색창에 이름을 치는 것처럼 찾습니다.

- 장소 이름만 있으면 됩니다. 지역·주소를 같이 적으면 더 정확해집니다.
- 결과마다 **찾음 / 확인 필요 / 못 찾음**을 표시하고, 후보 고르기·검색어 고치기·지도에서 직접 찍기로 바로잡을 수 있습니다.
- 날짜(또는 분류)별로 핀 색이 달라지고, 날짜 탭을 누르면 그날의 장소와 동선만 볼 수 있습니다.
- **동선**: 같은 날의 장소를 순서대로 잇고, 구간마다 실제 이동 경로(지하철·버스·도보)와 소요 시간을 찾아 줍니다.
- **여행 일정 추천**: 나라·지역과 날짜, 관심사를 넣으면 일정표를 만들어 지도에 바로 올립니다. Claude API 키가 있으면 Claude가 짜고 구글 지도로 확인합니다.
- **주변 명소·맛집**: 대표 장소 주변을 구글 평점·리뷰 수로 순위를 매겨 추천하고, 일본은 타베로그·한국은 카카오맵 링크를 함께 답니다.
- **하루 예산**: 메모에 적은 금액과 어림한 식비·교통비를 날짜별로 더해 예산과 견주고, 빈 끼니에 예산 안의 가게를 골라 엑셀에 넣습니다.
- 결과를 **좌표가 담긴 엑셀**이나 **KML**(구글 내 지도용)로 저장할 수 있습니다.

## 빠른 시작

1. `start.bat`을 더블클릭합니다. (또는 이 폴더에서 `npm start`)
   브라우저에 `http://localhost:8080`이 열립니다. Node.js만 있으면 되고, 따로 설치할 패키지는 없습니다.
2. 왼쪽 메뉴의 **설정**(또는 지도 안내의 「API 키 입력하기」)에서 구글 지도 API 키를 넣습니다. (아래 발급 방법 참고)
3. 엑셀을 올리고, 열이 맞게 연결됐는지 확인한 뒤 **지도에 표시하기**를 누릅니다.
4. 동선 카드의 **경로 찾기**를 누르면 구간마다 실제 이동 경로가 그려집니다.

처음이라면 화면의 **양식 내려받기**(또는 이 폴더의 `지도_양식.xlsx`)로 먼저 시험해 보세요.

## 구글 지도 API 키 발급 (처음 한 번)

1. [Google Cloud 콘솔](https://console.cloud.google.com/google/maps-apis/start)에서 새 프로젝트를 만듭니다.
2. **결제 계정**을 연결합니다. 카드 등록이 필요하지만, 매달 무료 사용량 안에서는 청구되지 않습니다.
3. **API 및 서비스 → 라이브러리**에서 다음을 **사용 설정**합니다.
   - `Maps JavaScript API`
   - `Places API (New)` ← 이름 끝에 **(New)**가 붙은 것이어야 합니다
   - `Routes API` ← 동선(이동 경로)을 쓸 때. 예전 `Directions API`는 새 프로젝트에서 켤 수 없으니 이것을 켭니다
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**로 키를 만듭니다.
5. (권장) 만든 키를 눌러 제한을 겁니다.
   - 애플리케이션 제한: **웹사이트** → `http://localhost:8080/*`
   - API 제한: `Maps JavaScript API`, `Places API (New)`, `Routes API`
6. 키를 앱 화면에 붙여 넣고 **저장**합니다.

키는 이 브라우저(localStorage)에만 저장됩니다. 공용 PC라면 다 쓴 뒤 **설정 → 칸을 비우고 저장**으로 지우세요.

## 엑셀 양식

평소 쓰는 여행 일정표에 **장소** 열 하나만 더하면 됩니다.

| 날짜 | 시간 | 일정 | **장소** | 지역 | 이동 수단 | 메모 |
|---|---|---|---|---|---|---|
| 11/29 (일) | 12:20–13:20 | 점심 (하카타 라멘) | 하카타역 | 후쿠오카 | | |
| 11/29 (일) | 13:20–13:35 | 하카타역 → 쿠시다 신사 | | | 도보 | |
| 11/29 (일) | 13:35–14:05 | 쿠시다 신사 참배 | 쿠시다 신사 | 후쿠오카 | | |

| 열 | 필수 | 설명 |
|----|----|---|
| 장소 | 필수 | 지도에 찍을 곳의 이름. 구글 지도 검색창에 쳐서 나오는 이름이면 됩니다. **비워 둔 행(이동·휴식 등)은 지도에 나오지 않습니다** |
| 지역 | 선택 | 같은 이름이 여러 곳에 있을 때 구분용 (예: `후쿠오카`, `부산 해운대구`) |
| 날짜 | 선택 | 날짜마다 핀 색이 달라지고, 날짜 탭으로 하루씩 볼 수 있습니다 |
| 주소 | 선택 | 알면 열을 추가해 적으세요. 장소 이름과 함께 검색합니다 |
| 위도 / 경도 | 선택 | 좌표가 있는 행은 검색하지 않고 그 위치에 바로 표시합니다 |
| 그 밖의 열 | 선택 | 시간·일정·이동 수단·메모 등 자유롭게. 핀 정보창에 함께 보입니다 |

작성 요령

- 장소 칸에는 **이름만** 적습니다. `쿠시다 신사 참배`가 아니라 `쿠시다 신사`. 하고 싶은 일은 일정 칸에 적으세요.
- `호텔`, `숙소` 대신 **실제 이름**을 적습니다 (예: `루트인 그란티아 다자이후`).
- **한 칸에 한 곳만.** `치노이케 지옥, 다쓰마키 지옥`처럼 두 곳을 들르면 행을 나눕니다.
- 해외 장소를 한국어로 못 찾으면 **현지어 이름**으로 적습니다 (예: `櫛田神社`). 일본어·영어로 적은 장소는 결과도 그 언어로 받아서 이름을 비교합니다.

그 밖에

- **머리글 이름은 달라도 됩니다.** `장소명`, `상호`, `업체명`, `분류`, `비고` 같은 흔한 이름은 자동으로 알아보고, 아니면 화면에서 직접 고르면 됩니다.
  날짜 열이 있으면 날짜를 핀 색 기준으로 먼저 고릅니다.
- 표 위에 제목·범례 줄이 있어도 되고, 시트가 여러 개면 고를 수 있습니다.
- `.xlsx`, `.xls`, `.csv`를 지원합니다. 한국어 엑셀이 저장한 CSV(EUC-KR)도 읽습니다.
- **공통 지역**에 `부산`처럼 적으면 모든 검색어 뒤에 붙습니다. 한 도시 안의 장소만 있을 때 정확도가 올라갑니다.

## 검색 결과 확인과 수정

검색어는 `장소 + (주소 또는 지역) + 공통 지역`으로 만들어 구글 Places API (New)의 Text Search로 찾습니다.
구글 지도 검색창과 비슷하게 동작하므로, 검색창에서 잘 나오는 이름이면 여기서도 잘 찾습니다.

| 상태 | 뜻 |
|---|---|
| 찾음 | 검색 결과 이름이 엑셀의 장소 이름과 맞음 |
| 확인 필요 | 결과 이름이 다르거나, 이름이 비슷한 곳이 여러 곳 나옴 (예: 지점명 없이 `스타벅스`) |
| 못 찾음 | 검색 결과가 없음 |

목록에서 항목을 누르면 다음과 같이 고칠 수 있습니다.

- **후보 고르기**: 검색 결과 최대 5곳 중 맞는 곳을 누릅니다.
- **다시 검색**: 검색어를 고쳐 다시 찾습니다.
- **지도에서 직접 찍기**: 지도에서 위치를 클릭합니다.
- **핀 끌기**: 선택한 핀은 끌어서 옮길 수 있습니다.

## 동선 (장소 사이 이동 경로)

일정표에 **날짜·시간·이동 수단** 열이 있으면 지도를 만든 뒤 자동으로 **동선 잇기**가 켜집니다.

1. 같은 날짜의 장소를 엑셀 순서대로 **파선 직선**으로 잇습니다 (요금 없음). 날짜가 다르면 잇지 않고, 같은 곳(호텔 체크인 → 호텔 온천 등)은 건너뜁니다.
2. **경로 찾기**를 누르면 구간마다 구글이 추천하는 실제 경로를 찾습니다.
   지도에는 대중교통·차는 실선, 도보는 동그란 점선으로 그리고, 목록의 장소 사이에 `공항선 → 도보 · 25분 · 4.2km`처럼 보여 줍니다.
3. 구간을 누르면 그 구간만 진하게 남고 나머지 구간은 흐린 파선으로 물러납니다. 탈 노선·타는 곳·내리는 곳·정거장 수·출발/도착 시각이 나오고, **이동 방법**을 바꾸거나 **구글 지도 길찾기**로 바로 열 수 있습니다 (여행 중 폰에서 쓰기 좋습니다).

경로를 정하는 방법

| 무엇을 | 어디서 읽나 |
|---|---|
| 이동 방법 | 두 장소 사이 행(장소가 빈 이동 행)과 도착 장소 행의 **이동 수단** 칸. `도보` → 도보, `지하철·버스·전철·JR·신칸센·특급·모노레일·KTX` → 대중교통, `택시·셔틀·차` → 차, `항공` → 직선. 비어 있으면 1.2km 이하는 도보, 그보다 멀면 대중교통 |
| 출발 시각 | 이동 행(이동 수단 칸이 채워진 행)의 시작 시각 → 없으면 앞 장소의 끝 시각 → 없으면 뒤 장소의 시작 시각을 도착 시각으로. 사이에 낀 짐 찾기·입국 심사 같은 행의 시각은 쓰지 않습니다. 날짜와 함께 그날 **시간표 기준** 대중교통을 찾습니다 (이 컴퓨터의 시간대 기준이며, 한국·일본은 같습니다) |

- 장소를 고치면(후보 선택·핀 끌기 등) 이어진 구간만 다시 찾습니다. 찾은 경로는 30일 동안 저장해 다시 쓰므로 같은 구간은 요금이 다시 들지 않습니다.
- 대중교통 경로는 **100일 뒤까지**만 시간표로 찾을 수 있습니다. 그보다 먼 날짜는 같은 요일·시각의 가까운 날로 대신 찾습니다.
- 하루의 출발지(숙소)도 지도에 잇고 싶다면 그날 첫 행에 숙소를 장소로 적으세요.
- **한국 안에서는** 구글이 도보·차 경로를 제공하지 않아 해당 구간이 "경로 없음"(직선)으로 나올 수 있습니다.
- **일본에서는** 도보·차 경로는 찾지만 **대중교통 경로는 API로 받을 수 없습니다** (2026년 10월 후쿠오카·기타큐슈에서 확인: 지하철·JR·버스 모두 결과 없음. 서울·런던은 정상).
  이런 구간은 일정표의 이동 시각으로 시간을 셈해 `일정표 기준 50분 · 구글 경로 없음`처럼 보여 주니, 길은 **구글 지도 길찾기**로 확인하세요.

## 일정 점검 (이동 시간이 모자란 구간 고치기)

경로를 찾으면, 일정표에 잡아 둔 이동 시간이 구글 경로 시간보다 모자란 구간을 **일정 점검**에 모아 보여 줍니다.

| 구간 | 알리는 기준 |
|---|---|
| 이동 행이 있는 구간 | 이동 행에 잡은 시간보다 **4분 이상** 더 걸릴 때. 도착지가 `[고정]` 일정이면 1분이라도 |
| 이동 행 없이 붙어 있는 두 장소 | 걸어서 **15분 이상** 걸릴 때 (가까운 곳끼리는 일정 안에서 걷는다고 봅니다) |

- 잡아 둔 이동 시간은 앞 장소 일정이 끝난 때부터 마지막 이동 행이 끝날 때까지에서, 사이에 낀 다른 일정(짐 찾기·점심 등)을 뺀 시간입니다.
- 걸어서만 찾은 길(대중교통 경로가 없어 대신 찾은 길 포함)은 대중교통·차 계획과 비교하지 않습니다.

**여유 정도**: 일정 점검 상자에서 고르면 구글 소요 시간에 여유를 더해 판단합니다 (이 브라우저에 기억).

| 여유 정도 | 걷는 시간 | 이동마다 | 탈 때마다 | `[짐]` 이동 |
|---|---|---|---|---|
| 빠듯하게 (기본) | 구글 그대로 | — | — | — |
| 보통 | 15% 더 | — | 2분 | 5분 |
| 여유롭게 | 30% 더 | 5분 | 5분 | 10분 |

- **이동마다**: 나설 채비·도착해서 입구 찾기. 이동 행이 있는 구간에만 더하고, 이동 행 없이 붙어 있는 관광지 사이에는 걷는 시간 배율만 씁니다.
- **탈 때마다**: 대중교통 노선 하나, 차(택시·셔틀) 한 번마다. 승강장 찾기·환승·기다리기.
- **`[짐]` 이동**: 이동 행에 `[짐]`이라고 적은 구간. 출발 행의 `[짐]`(예: 코인로커에 짐 보관)은 짐을 맡기고 빈손으로 걷는 경우라 세지 않습니다.
- 값은 `js/plan.js`의 `PACES`에서 바꿀 수 있습니다.

**놓치면 오래 기다리는 차**: 배차가 긴 차를 놓치면 다음 차까지 일정이 통째로 밀리므로, 타기 직전 앞 일정과 띄워 둔 시간을 봅니다.
구글 경로 없이 일정표만으로 정하므로, 경로를 찾기 전에도, 대중교통 경로가 안 나오는 일본에서도 동작합니다.

- 대상: 장소 칸이 빈 이동 행 중 배차가 20분 이상이거나, 첫차·막차이거나, `[고정]`인 차 (항공은 제외)
- 배차: 그 행에 적힌 `시간당 4~5대`(→ 15분, 적게 다니는 쪽으로), `20~30분 간격`, `배차 12분`, `1시간마다`, `하루 6편`을 먼저 읽고,
  없으면 이동 수단 글자로 짐작합니다 — 특급·급행·공항버스·리무진·고속/시외버스·셔틀·페리·KTX/SRT 약 30분, 버스·전철·JR·신칸센 약 15분, 지하철·모노레일·트램 약 5분
- 여유 = 차가 떠나는 시각 − 같은 날 바로 앞 행이 끝나는 시각. 여유 정도에 따라 빠듯하게 5분 · 보통 10분 · 여유롭게 15분보다 짧으면 알립니다
- 고침안 **앞 일정 당기기**: 바로 앞 일정의 끝을 당기고, 그 사이 걷는 이동 행은 걸리는 시간은 두고 통째로 당깁니다.
  앞 일정에 도착 시각만 있거나(버스로 도착 등) 그 앞에 또 탈 차가 있으면 고칠 수 없다고 알려 줍니다
- 장소 행의 이동 수단 칸(예: 다케가와라 온천 · `도보 10분`)은 그곳까지 가는 방법이라 이동 행으로 보지 않습니다

구간을 누르면 5분 단위 고침안 두 가지가 나옵니다.

- **앞 일정 줄이기**: 이동 바로 앞 일정(앞 장소, 또는 그 뒤의 점심·짐 찾기)의 끝 시각을 당기고, 이동 행의 출발 시각도 함께 당깁니다.
- **뒤 일정 미루기**: 이동 뒤 첫 일정(휴식, 또는 도착 장소)의 시작 시각을 늦추고, 이동 행의 끝 시각도 함께 늦춥니다.
- `[고정]`이 적힌 행(항공·예약)과 시간 칸이 수식인 행은 바꾸지 않습니다. 남는 일정이 5분보다 짧아지거나 다음 일정과 겹치면 고를 수 없습니다.

고친 칸은 일정 점검 아래에 `원래 → 새 시각`으로 쌓이고, **고친 일정 엑셀로 저장**을 누르면 원래 파일에서 **그 시간 칸만 바꾼 사본**(`원래이름_수정.xlsx`)을 내려받습니다. **모두 되돌리기**로 처음 시각으로 돌아갈 수 있습니다.

- `.xlsx`는 파일 안에서 해당 칸만 바꾸므로 글꼴·색·테두리·열 너비·틀 고정이 그대로 남습니다. 시간 칸이 엑셀 시간 값이면 시간 값으로 씁니다.
- `.csv`는 CSV로, `.xls`는 `.xlsx`로 저장하며, 이때는 서식이 남지 않습니다.

## 여행 일정 추천

엑셀이 없어도 됩니다. **여행 일정 추천받기** 칸에 나라·지역(예: `규슈`, `오사카·교토`), 출발일, 며칠, 숙소(선택), 이동 방법, 여유 정도, 하루 예산, 관심사를 넣고 **일정 짜기**를 누르면 앱의 일정표 모양(날짜·시간·일정·장소·지역·이동 수단·메모·주소·위도·경도) 엑셀을 만들어 엑셀을 올렸을 때처럼 지도에 올립니다. 그다음은 경로 찾기, 일정 점검, 하루 예산, 빈 끼니의 맛집 추천을 그대로 씁니다. **추천 일정 엑셀 내려받기**로 파일을 받을 수 있고, 일정 점검에서 고친 칸도 그 파일에 써 넣습니다.

| | Claude API 키가 있을 때 | 없을 때 |
|---|---|---|
| 누가 짜나 | Claude(Opus 5.5)가 도시 배분·동선·시각·교통편·입장료·팁을 짜고, 앱이 장소마다 구글 지도에서 찾아 위치를 붙입니다 | 그 지역에서 구글 평점·리뷰 수가 높은 곳을 골라 가까운 곳끼리 날짜별로 묶고, 머무는 시간과 거리로 시각을 매깁니다 |
| 맞는 여행 | 나라·여러 도시(예: 규슈 5일 → 후쿠오카·벳푸·유후인), 근교 당일치기 | 도시 하나 며칠 |
| 확인 | 구글에서 못 찾은 곳, 찾은 이름이 다른 곳, 그 요일·시각에 닫는 곳, 그날 다른 곳과 너무 먼 곳을 `확인이 필요한 곳`으로 보여 주고, **Claude에게 고쳐 달라고 하기**로 그 부분만 다시 받습니다 | 그날 쉬는 곳은 다른 날과 맞바꾸거나 그날 여는 다음 후보로 바꿉니다 |
| 끼니 | 가게는 정하지 않고 `점심 (캐널시티 하카타 주변) (하카타 라멘·모츠나베)`처럼 빈 자리로 둡니다. 하루 예산의 **맛집 추천**이 괄호 속 장소 주변에서 그 음식으로 찾습니다 | 같음 (`점심 (OO 주변)`) |
| 비용 | Anthropic 요금으로 일정 하나에 약 $0.2~0.3 + 장소 확인(구글 Text Search Enterprise) 장소 수만큼 | 구글 검색 5~10건 |

**Claude API 키**: [Anthropic 콘솔](https://console.anthropic.com/settings/keys)에서 만들고 크레딧을 충전합니다(Claude 구독과는 별개). 설정의 **Claude API 키** 칸에 넣으면 이 브라우저에만 저장되고, 서버 없이 브라우저에서 Claude API로 바로 보냅니다(SDK의 `dangerouslyAllowBrowser`). 그래서 공용 PC에는 넣지 말고, 콘솔에서 월 사용 한도를 걸어 두세요. 공개 사이트로 운영한다면 각자 자기 키를 넣는 구조이고, 키를 사이트에 넣어 두면 안 됩니다.

- 요청은 Claude가 정해진 JSON 모양(구조화 출력)으로만 답하게 하고, 안전 분류기가 거절하면 서버가 알맞은 모델로 다시 돌리는 `fallbacks: "default"`를 켜 둡니다.
- 출발일을 비우면 `1일차`, `2일차`로 짜고 영업일 확인은 하지 않습니다.

## 주변 명소·맛집

일정의 장소를 누르고 **주변 맛집 / 카페 / 주변 명소**를 고르거나, 추천 칸에 대표 장소 이름을 적으면 걸어갈 만한 곳(맛집·카페 800m, 명소 1.5km)을 찾아 순위를 매깁니다. 엑셀을 올리지 않아도 쓸 수 있습니다.

| 기준 | 하는 일 |
|---|---|
| 평점 | 구글 평점을 리뷰 수로 보정합니다(베이즈 평균). 리뷰 3개짜리 5.0점보다 리뷰 800개짜리 4.3점이 위로 옵니다. 명소는 리뷰가 많은 곳을 조금 더 올립니다 |
| 거리 | 걸어서 5분을 넘으면 1분마다 조금씩 내립니다 |
| 영업시간 | 일정의 그 요일·시각(일정이 없으면 지금)에 닫았거나 곧 닫는 곳은 뒤로 보냅니다 |
| 예산 | 빈 끼니에서 찾으면 그날 남은 돈 안에 드는지 보고, 넘는 곳은 `예산 초과`로 표시해 뒤로 보냅니다 |
| 일정 | 이미 일정에 있는 곳은 `일정에 있음`으로 맨 뒤에 둡니다. 명소에서는 큰 신사의 누문처럼 바로 옆의 딸린 곳을 뺍니다 |

**평점 사이트**: 일본 가게는 **타베로그**, 한국은 **카카오맵** 링크를 함께 답니다. 두 곳은 점수를 가져다 쓸 수 있는 공개 API가 없고(카카오 로컬 API는 평점을 주지 않습니다), 타베로그는 약관으로 점수·리뷰의 복제와 재이용을 금지하므로 앱이 점수를 읽어 오지 않습니다. 대신 링크에서 본 점수를 옆 칸에 적으면 순위에 반영하고(타베로그 3.0 → 구글 3.6, 3.5 → 4.3, 4.0 → 5.0으로 바꿔 구글 점수와 평균), 이 브라우저에 기억합니다. 그 밖의 나라는 구글 평점만 씁니다.

- 가게를 누르면 칸이 펼쳐져 **사진 3장, 한 줄 소개, 특징**(예약·포장·현금만·아침/점심/저녁 영업 등), **리뷰 요약과 리뷰 3개**(한국어로 쓴 리뷰가 먼저), 요일별 영업시간(일정의 그 요일을 굵게), 주소·전화·웹사이트, 대표 장소에서 걸어가는 길찾기가 나옵니다. 지도 말풍선에도 사진이 들어갑니다.
- 일본 가게는 일본어 이름으로 찾습니다. 간판과 같고, 타베로그에서 바로 찾을 수 있습니다(타베로그 링크는 그 현(県) 안에서 가게 이름으로 검색).
- 하루 예산의 **빈 끼니**(장소가 빈 `점심`·`저녁` 같은 행)에서 **맛집 추천**을 누르면 그때 있을 곳 주변에서 찾습니다. `아침 (하카타역 주변)`처럼 괄호에 장소를 적었으면 그곳을, `점심 (하카타 라멘·모츠나베)`처럼 음식을 적었으면 그 말로 찾습니다.
- **이 가게로 정하기**를 누르면 그 행의 장소·주소·위도·경도 칸을 채우고 메모에 가격대를 덧붙입니다. 지도와 동선, 일정 점검에 바로 들어가고, 일정 점검의 **고친 일정 엑셀로 저장**으로 원래 파일에 써 넣을 수 있습니다.
- 평점·가격대 같은 장소 정보는 구글 약관에 따라 저장해 두지 않고 페이지를 연 동안만 기억합니다. 새로 고침한 뒤 같은 곳을 다시 찾으면 다시 요청합니다.

## 하루 예산

1인 기준, **숙박·항공은 빼고** 날짜별 지출을 더합니다. 예산을 원으로 적고 일본 일정이면 환율(유럽중앙은행 기준, [frankfurter.dev](https://frankfurter.dev))로 바꿔 견줍니다.

| 지출 | 어디서 |
|---|---|
| 메모·일정에 적은 금액 | `1,800엔`, `¥1,000–2,000`, `1만 5천원`, `$12` 등을 읽습니다. 범위면 가운데 값으로 셉니다. `+2,200엔`·`별도`는 선택 비용, `대안:` 뒤의 금액은 다른 선택지로 보고 더하지 않습니다 |
| 끼니 | 금액이 없으면 보통 값(일본 아침 900·점심 1,300·저녁 3,000·카페 700엔, 한국 9,000·13,000·25,000·6,500원)으로 어림합니다. 추천에서 가게를 고르면 그 가게의 가격대를 씁니다 |
| 교통 | 구글 경로에 요금이 있으면 그 값, 없으면 이동 수단과 일정표의 이동 시간으로 거리를 어림해 셉니다. 일본은 구글이 대중교통 경로를 주지 않아 모두 어림값입니다. `무료` 셔틀은 0원, `버스 1일권`을 산 날의 버스는 1일권으로 봅니다 |
| 코인로커 | `코인로커에 짐 보관` 행은 하루 요금(일본 600엔, 한국 3,000원)으로 어림합니다 |
| 입장료 | 메모에 적은 것만 더합니다 |

- 금액을 누르면 직접 고칠 수 있고, 고친 금액은 같은 파일·시트에서 다시 열어도 남습니다(이 브라우저).
- 끼니는 행 이름의 `아침·조식`, `점심·런치`, `저녁·디너`, `카페` 같은 말로 알아봅니다. 음식 이름만 적힌 행(`스시 쿠보타 오마카세 코스`)은 30분 넘게 머물 때 시각으로 끼니를 정합니다.
- 어림값은 대략입니다. 특히 오마카세처럼 비싼 끼니나 장거리 열차는 실제 금액을 적어 두세요.

## 저장하기

- **엑셀로 저장 (좌표 포함)**: 원래 열은 그대로 두고 `위도`, `경도`, `검색된 이름`, `검색된 주소`, `구글지도 링크`, `구글 장소 ID`, `검색 상태`, `다음 장소까지`(동선 요약) 열을 채웁니다.
  이 파일을 다시 올리면 **검색 없이 바로** 지도에 표시되므로 요금이 들지 않습니다.
- **KML로 저장**: [구글 내 지도](https://www.google.com/mymaps)에서 **새 지도 만들기 → 가져오기**로 KML을 올리면, 링크로 다른 사람과 공유할 수 있는 지도가 됩니다.
  동선을 켜 두었으면 구간 선도 함께 들어갑니다.
  (내 지도가 핀 색을 자체 스타일로 바꿀 수 있어, 색은 그곳에서 다시 지정해야 할 수도 있습니다.)

- 경로 요청에 대중교통 요금(`travelAdvisory`)을 함께 받아도 Essentials 등급 그대로입니다(통행료 계산을 따로 켜야 등급이 오릅니다).
- 걱정된다면 콘솔의 **결제 → 예산 및 알림**에서 금액 알림을 걸고, **Places API (New) → 할당량**에서 분당 요청 수를 낮출 수 있습니다.

## 알아둘 점

- **한국 장소 데이터**: 구글 지도는 한국에서 네이버·카카오 지도보다 상호 정보가 적은 편이라, 작은 가게는 못 찾을 수 있습니다.
  지점명과 지역을 함께 적으면 대부분 해결됩니다. 그래도 부족하면 카카오 로컬 API를 검색 엔진으로 추가할 수 있습니다 (`js/places.js`만 바꾸면 되는 구조입니다).
- **구글 약관**: Places 검색 결과의 좌표는 최대 30일까지만 저장할 수 있고, 장소 ID는 계속 저장할 수 있습니다. 또 검색 결과는 구글 지도 위에 표시해야 합니다.
  개인·팀 내부용으로는 문제가 없지만, 공개 서비스로 키울 계획이라면 좌표 대신 장소 ID를 보관했다가 위치를 다시 불러오는 방식으로 바꾸는 것이 안전합니다.
- **지도 ID**: `config.js`의 `DEMO_MAP_ID`는 시험용입니다. 오래 쓸 거라면 콘솔의 **지도 관리**에서 Map ID를 만들어 바꾸세요.
