# RouteFlow

**가고 싶은 곳을 모으고, 지도에서 여행 일정을 완성하세요.**

RouteFlow는 장소를 보관했다가 날짜별 일정에 배치하고, 이동 동선을 확인하는 여행 일정 편집기입니다. 빈 여행으로 시작하거나 이미 작성한 엑셀 일정표를 가져올 수 있습니다.

[**RouteFlow 시작하기 →**](https://wer134.github.io/HowdoIgetthere/)

## 이렇게 사용할 수 있어요

- **장소 모으기** — 가고 싶은 장소를 검색해 보관하고 개인 메모를 남깁니다.
- **날짜별 일정 만들기** — 장소를 날짜와 방문 순서에 맞춰 배치합니다. 데스크톱에서는 드래그, 모바일에서는 버튼을 사용할 수 있습니다.
- **지도와 동선 확인** — 날짜별 장소를 지도에서 보고, 필요할 때 실제 이동 경로를 요청합니다.
- **일정 다듬기** — 장소·시간·메모를 수정하고, 이동 시간이 부족한 구간을 확인합니다.
- **저장하고 이어 하기** — 같은 브라우저에서 저장한 여행을 다시 열거나 엑셀·KML로 내보냅니다.

## 처음 시작하기

### 새 여행 만들기

1. **새 여행 시작**을 누르고 여행 이름, 출발일, 여행 일수를 입력합니다.
2. **가고 싶은 곳 → 직접 장소 보관**에 이름·주소·메모를 적거나, Google Maps 연결 후 지역과 장소를 검색합니다. 예: `후쿠오카 오호리공원`.
3. **보관하기**로 후보를 모으거나 **일정에 넣기**로 날짜와 삽입 위치를 선택합니다.
4. **일정** 탭에서 방문 순서와 시간을 조정합니다.
5. 이동 시간을 확인하려면 **경로 찾기**를 누릅니다.

여행 생성과 메모 편집은 지도 연결 없이 시작할 수 있습니다. 장소 검색·지도·경로 기능에는 Google Maps API 키가 필요합니다.

### 기존 엑셀 가져오기

1. **엑셀 가져오기**로 `.xlsx`, `.xls`, `.csv` 파일을 엽니다.
2. 장소·날짜·시간 등의 열이 올바르게 연결됐는지 확인합니다.
3. **지도에 표시하기**를 누르고, 검색 결과가 맞는지 확인합니다.

처음이라면 [엑셀 양식](지도_양식.xlsx)을 사용해 보세요.

| 날짜 | 시간 | 장소 | 지역 | 메모 |
|---|---|---|---|---|
| 2026-11-01 | 10:00–11:00 | 오호리공원 | 후쿠오카 | 산책 |
| 2026-11-01 | 12:00–13:00 | 방문할 식당 이름 | 후쿠오카 | 점심 |

장소 이름에 지역이나 주소를 함께 제공하면 검색 정확도가 좋아집니다. 위도·경도가 있는 행도 사용할 수 있습니다. 장소·주소·좌표가 모두 없는 행은 지도 핀으로 표시되지 않습니다. 일부 입력 화면에는 장소 열 연결이 필요합니다.

## AI로 하루 일정 수정하기

작성한 엑셀이나 저장한 여행을 지도에 표시한 뒤 **AI로 하루 일정 수정**을 누릅니다.

1. 수정할 날짜를 고르고, 예약처럼 유지할 항목에 **장소·시간 유지**를 체크합니다.
2. “오후에는 덜 걷고 싶어요”, “미술관을 오후로 옮기고 카페를 추가해 주세요”처럼 요청합니다.
3. **수정안 만들기**를 누르고 현재 일정과 AI 수정안을 비교합니다. 제외될 일정도 표시됩니다.
4. **이 날짜에 적용**을 누르면 해당 날짜만 바뀝니다. 개인 메모·추가 열·다른 날짜·보관함은 보존되며, 바로 **되돌리기**할 수 있습니다.
5. **경로 찾기**로 바뀐 일정의 실제 이동 시간을 확인합니다.

설정한 AI 제공업체의 키와 API 요금을 사용합니다. 선택한 날짜의 장소·시각·메모·좌표와 수정 요청을 전송합니다. 새 장소는 Google 위치 확인이 완료돼야 적용할 수 있습니다. 저장 실패나 다른 탭의 수정과 충돌하면 원본을 유지합니다. 날짜가 연결된 1~100행의 하루를 수정할 수 있습니다.

## 장소와 일정 수정하기

| 하고 싶은 일 | 사용할 기능 |
|---|---|
| 후보 장소를 남겨 두기 | **가고 싶은 곳 → 보관하기** |
| 날짜를 정해 방문하기 | **일정에 넣기** |
| 날짜 또는 순서 바꾸기 | 일정 항목의 **이동** |
| 장소·시간·메모 고치기 | **수정** |
| 일정에서 빼고 후보로 남기기 | **보관함으로** |
| 일정 항목 제거하기 | **삭제** |
| 방금 변경 취소하기 | 알림의 **되돌리기** |

같은 장소를 여러 날에 배치할 수 있습니다. 보관함에서 장소를 지워도 이미 배치한 일정은 지워지지 않습니다. 보관함 배치 변경 후에는 **경로 찾기**로 실제 경로를 갱신하세요.

## 여행을 옮기고 여행 중 펼쳐 보기

- **여행 도구 → 여행 전체 백업**은 일정·보관한 후보·개인 메모·빈 날짜를 함께 담은 파일을 만듭니다. 다른 브라우저에서 **백업 불러오기**로 열면 별도 복원본이 생기며 기존 여행은 유지됩니다. API 키·사진·리뷰는 포함하지 않습니다.
- **여행 도구 → 일정표 보기**에서 전체 일정과 후보를 읽거나 **인쇄 / PDF**로 보관하세요. **일정표 파일 저장**으로 받은 HTML 파일은 인터넷 없이 열 수 있습니다.
- 모바일에서는 아래 **저장** 메뉴에서도 전체 백업과 일정표를 이용할 수 있습니다.
- 여행 이름 옆 **이름 변경**으로 제목을 바꿀 수 있으며, 다시 방문하면 첫 화면의 **이어서 준비하기**로 최근 여행을 엽니다.

백업과 일정표에는 저장한 변경 사항이 담깁니다. 편집창에 입력 중인 내용은 먼저 저장하세요. 다운로드 후 브라우저에서 파일이 실제로 저장되었는지 확인해 주세요.

## 지도 연결과 이용 요금

현재 공개 버전은 사용자가 설정한 API 키를 이용합니다. **설정**에서 Google Maps API 키를 저장하세요. 키를 만든 Google Cloud 프로젝트에는 다음 API가 필요합니다.

- `Maps JavaScript API`
- `Places API (New)`
- `Routes API` — 실제 이동 경로를 이용할 경우

[Google Cloud 콘솔](https://console.cloud.google.com/google/maps-apis/start)에서 결제 설정과 API 사용 설정을 확인할 수 있습니다. 웹사이트 제한에는 실제 사용하는 사이트 주소를 등록하세요. 공개 사이트의 예시는 `https://wer134.github.io/*`입니다.

**지도·장소 검색·사진·경로 요청에는 Google 사용 요금이 발생할 수 있습니다.** 키가 속한 결제 계정에 청구되며, 무료량과 단가는 [Google 공식 가격표](https://developers.google.com/maps/billing-and-pricing/pricing)를 확인하세요. 저장된 여행을 열어도 지도와 사진 등의 추가 요청이 발생할 수 있습니다.

AI 일정 추천은 선택 기능입니다. 설정에서 지원하는 제공업체를 고르고 해당 API 키를 입력합니다. ChatGPT·Claude·Gemini의 일반 구독과 API 요금은 별개입니다. API 키는 채팅이나 공개 저장소에 올리지 마세요.

## 내 여행은 어디에 저장되나요?

- 일정과 보관함은 **현재 브라우저에 자동 저장**됩니다. **저장한 여행**에서 다시 열 수 있습니다.
- 계정 로그인이나 기기 간 동기화 기능은 없습니다. 브라우저 데이터 삭제·기기 변경 시 여행을 다시 열지 못할 수 있습니다.
- 중요한 여행은 **여행 전체 백업**으로 후보와 메모까지 함께 보관하세요. **엑셀 저장**은 일정표를 별도로 내보냅니다. **KML 내보내기**는 지도 프로그램에서 장소를 열 때 사용할 수 있습니다.
- 저장 공간이 부족하면 안내가 표시됩니다. 자동 저장만을 유일한 백업으로 사용하지 마세요.
- 여행 이력은 일정 데이터로 복원되며, 원본 엑셀의 글꼴·색·배치까지 보존하지 않습니다.

엑셀은 브라우저에서 읽습니다. 장소를 검색할 때에는 검색어·지역·좌표 등의 필요한 정보가 Google로 전송되고, AI 추천 시에는 여행 조건과 재추천에 필요한 일정 정보가 선택한 AI 제공업체로 전송됩니다. 설정에 입력한 키는 이 브라우저에 저장됩니다. 공용 기기에서는 키 입력칸을 비우고 저장한 뒤, 여행 이력과 사이트 데이터도 정리하세요.

## 사용 전에 알아두세요

- 동명이 있는 장소는 검색 결과를 직접 확인하세요. 후보 선택이나 지도에서 직접 위치 지정으로 수정할 수 있습니다.
- 사진·한국어 설명이 제공되지 않는 장소도 있습니다.
- 일부 국가·지역은 대중교통 경로를 제공하지 않습니다. 예약·막차·휴무·영업시간은 방문 전 공식 안내에서 확인하세요.
- 자동 추천과 이동 시간은 계획을 돕는 참고 정보입니다. 현지 상황과 실제 운영 시간에 따라 달라질 수 있습니다.
