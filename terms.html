RouteFlow 이용 안내

최종 수정: 2026-11-04. 이 안내는 여행 편집 도구와 선택형 계정·외부 API 사용 범위를 설명합니다.

제공 기능

로그인 없이 여행을 만들거나 엑셀을 가져와 날짜별로 편집·기기 저장·파일 백업할 수 있습니다. 계정 서버가 연결된 설치에서는 Google 로그인 후 선택한 여행을 계정으로 복사하고 동행자의 장소 제안을 받을 수 있습니다. 최종 일정 편집과 제안 수락은 여행 주인이 담당합니다. 실시간 공동 편집, 여행 예약·결제 기능은 제공하지 않습니다.

외부 API와 비용

개인 Google Maps 및 AI 키를 사용하는 경우 외부 API 이용료는 해당 제공업체의 계정·요금제·쿼터에 따라 발생할 수 있습니다. API 키를 공유하지 말고 사용량 제한을 설정하세요. 키 없이도 직접 일정과 메모를 작성할 수 있습니다.

운영자 비용의 무료 AI는 설치에서 활성화한 경우에만 제공하며, 로그인·전화 인증·본인 소유 계정 여행과 사용량 한도가 적용됩니다. 무제한 사용을 보장하지 않습니다. 수동 편집과 저장, 개인 API 키에는 전화 인증이 필요하지 않습니다. 전화 인증은 법적 실명 확인을 뜻하지 않습니다.

공유와 저장

읽기 공유 링크의 소지자는 일정·후보·메모를 열람할 수 있습니다. 민감한 내용을 포함하지 말고 필요한 경우 링크를 취소하세요. 로그인만으로 기기 여행이 계정에 업로드되지는 않습니다.

저장 실패나 충돌이 표시되면 저장이 완료된 것이 아닙니다. 계정의 미전송 편집 임시본은 탭 종료 후 보존을 보장하지 않으므로 탭을 닫기 전에 파일 백업을 내려받으세요. 기기 변경·브라우저 초기화 전에도 중요한 여행을 백업하세요.

일정과 장소 확인

AI 제안은 적용 전에 검토하세요. 영업시간, 휴무, 요금, 교통편과 예약 가능 여부는 방문·결제 전에 공식 출처로 확인해야 합니다. 경로 검색 전 연결선이나 추정값은 실제 이동 경로가 아닙니다. 자정을 넘는 일정은 날짜를 나누어 기록하세요.

외부 콘텐츠와 문의

Google 지도·사진·리뷰 등의 출처 표시와 이용 조건을 지켜 주세요. 코드와 라이브러리의 권리 안내는 저작권 안내와 외부 고지에서 확인할 수 있습니다.

프로젝트 문의: RouteFlow GitHub Issues. 실제 계정 서비스를 운영하기 전에 운영 주체·비공개 연락처·개인정보 보관 및 삭제 정책을 확정해야 합니다. 유료 상품을 도입한다면 요금·환불 정책도 별도로 게시해야 합니다.
