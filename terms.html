RouteFlow 이용 안내

최종 수정: 2026-10-31. 이 안내는 현재 제공되는 여행 편집 도구와 외부 API 사용 범위를 설명합니다.

제공 기능

직접 작성한 일정이나 엑셀을 지도에 표시하고 날짜별로 편집·백업할 수 있습니다. 현재 회원가입, 공동 편집, 클라우드 동기화, 여행 예약·결제 기능은 제공하지 않습니다.

외부 API와 비용

공개 웹앱에서는 사용자가 입력한 Google Maps 및 AI 제공업체의 키를 사용합니다. 외부 API 이용료는 해당 제공업체의 계정·요금제·쿼터에 따라 발생할 수 있습니다. API 키를 다른 사람과 공유하지 말고 사용량 제한을 설정하세요. 키가 없어도 직접 일정과 메모를 작성할 수 있습니다. 지도와 AI 기능에는 각각 해당 키가 필요합니다.

일정과 장소 확인

AI 수정안은 적용 전에 검토하세요. 영업시간, 휴무, 요금, 교통편과 예약 가능 여부는 방문·결제 전에 공식 출처로 확인해야 합니다. 경로 검색 전 연결선이나 추정값은 실제 이동 경로가 아닙니다. 자정을 넘는 일정은 날짜를 나누어 기록하세요.

데이터 보관

기기 변경·브라우저 초기화 전에 백업을 내려받으세요. 브라우저에 저장된 여행은 자동으로 다른 기기에 동기화되지 않습니다. 저장 실패 안내가 나타나면 엑셀 또는 백업으로 별도 보관해 주세요.

외부 콘텐츠와 문의

Google 지도·사진·리뷰 등의 출처 표시와 이용 조건을 지켜 주세요. 코드와 포함된 라이브러리의 권리 안내는 저작권 안내와 외부 고지에서 확인할 수 있습니다.

프로젝트 관리·문의: RouteFlow GitHub Issues. 유료 상품·계정 서비스를 도입할 때에는 별도의 운영 주체, 연락처, 요금·환불 및 개인정보 정책을 확정해 게시해야 합니다.
