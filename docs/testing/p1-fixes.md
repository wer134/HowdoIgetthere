# P1 저장 데이터 보호 수정 검증

2026-10-30. 기존 `negative-tests-78.md`는 de2ecb4에서 확인한 기준 보고서로 보존한다.

- 8번: Web Locks로 동일 출처의 저장·삭제를 직렬화하고, 로드한 저장본과 현재 저장본을 비교한다. 충돌 시 원격 저장본을 보존하고 로컬 편집 내용과 경고를 유지한다. 삭제된 여행도 오래된 탭에서 다시 저장하지 않는다.
- 9번: 여행 전환과 파일 전환 시 이전 undo를 해제하고, undo 콜백에 여행 ID 검사를 추가했다.
- 60번 및 관련 58번: 저장 키와 내부 ID, 배열·필드 타입을 검사한다. 손상 항목은 원본을 보존하고 목록에서 제외하며 정상 여행은 계속 열 수 있다. 삭제 저장 실패도 성공처럼 처리하지 않는다.

검증: `npm test` 39개 통과. `tests/browser/travel-safety.cjs`의 5개 시나리오 통과([결과](evidence/p1-fixes/results.json)). 기존 `travel-workspace.cjs`의 데스크톱/모바일 검사와 `travel-order.cjs`도 통과했다. 저장 목록이 비동기로 갱신되므로 기존 순서 검사는 모달이 열린 뒤 동일한 개수 조건을 확인하도록 대기만 추가했다.

안전성 검증에는 실제 Google API를 호출하지 않았다. 78개 전체를 새로 통과했다고 주장하지 않으며, 나머지 항목의 기준 결과는 기존 보고서를 참고한다. Web Locks를 제공하지 않는 브라우저에서는 자동 저장 대신 엑셀 저장 안내를 표시한다. 페이지가 강제로 종료될 때 진행 중인 비동기 저장의 완료는 보장하지 않는다.

재현: 서버를 실행한 뒤 `APP_URL=http://127.0.0.1:8093 node tests/browser/travel-safety.cjs`. `RESULT_PATH`를 지정하면 결과 JSON을 저장한다.
