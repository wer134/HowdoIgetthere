2026-10-31 (Asia/Seoul). `wer134/HowdoIgetthere`의 main `de2ecb4`에서 이어진 로컬 `work` 브랜치, 앱 코드 `f26d23b` 기준. 별도 Chromium 프로세스·비영속 브라우저에서 테스트 여행만 만들었다. 주소는 `http://127.0.0.1:8093/`이다.

## 실제 호출과 모의 검사의 구분

- 단위 테스트: **50/50 통과**. 제공업체 오류·요청 형식은 모의 HTTP 응답, 엑셀 날짜·런타임 직렬화는 실제 로컬 로직 검사다. [실행 로그](evidence/live-api-2026-10-31/unit-tests.txt).
- 환경 설정 브라우저 검사: 세 조건 통과. 두 환경 값 전달·캐시 금지, 새 브라우저의 기본 제공업체·모델과 키 비영속화, 빈 AI 키 저장 후 새로고침 시 사용 중지. 외부 API를 차단한 구성 검사다. [결과](evidence/live-api-2026-10-31/runtime-settings.json), [재현 코드](../../tests/browser/runtime-settings.cjs).
- Google 실제 호출 성공 응답에는 지도 타일·설정·장소·사진 등이 포함된다. HTTP 건수를 과금 건수로 해석하지 않았다. Gemini 응답의 토큰 사용량은 각 증거 JSON에 보존했으며 청구액은 확인하지 않았다.
- 관리형 프록시와 제공 CA를 사용했고 TLS 검증을 끄지 않았다. Google Fonts와 환율 제공자 `api.frankfurter.dev`는 현재 네트워크 정책에서 차단돼 실시간 검증 불가다. 일부 `maps.gstatic.com` 요청에는 이동/종료 과정의 취소가 기록돼 있다. 지도·검색·경로 성공과 별도로 남긴다.
- 기존에 제외하기로 한 8개 항목은 검증 불가 상태를 유지한다. 실제 지도 확대 성공을 핀 드래그·모바일 제스처·스크린리더 등의 통과로 대체하지 않는다.

## 로컬 재현 환경

Node 24.19.0, Chromium 154.0.8037.57, Playwright 1.62.1. 실제 API 화면 검사는 1440×900, 한국어 로캘이다. 모의 78개 검사는 항목별 독립 BrowserContext와 Asia/Seoul 시간대를 사용하며 시간대 변경 항목은 별도 조건으로 실행한다.

환경에 `googlemap`·`geminiapi`가 설정돼 있어야 한다. Google 키의 웹사이트 제한에 테스트 주소 패턴 `http://127.0.0.1:8093/*`를 허용하고 관련 API를 활성화한다. 프록시 환경의 Chromium에는 환경 CA 신뢰를 설정한다. 사용자 브라우저 프로필을 공유하지 않는다.

```bash
PORT=8093 node server.js --no-open
# 별도 터미널
npm test
APP_URL=http://127.0.0.1:8093 node tests/browser/runtime-settings.cjs
APP_URL=http://127.0.0.1:8093 NEGATIVE_OUT=/tmp/negative-78-recheck node docs/testing/repro/negative-78.cjs
```

실제 API 시나리오는 위 표의 UI 절차를 따른다. 78개 자동 검사는 외부 요청을 차단하고 테스트용 SDK/지도와 키를 사용한다. 환경의 실제 키가 모의 검사의 수동 키 UI를 숨기지 않도록 `/runtime-config.js` 응답도 빈 테스트 구성으로 격리했다. 환경 키 전달 자체는 앞의 별도 구성 검사에서 확인한다.

78개 검사의 첫 시도는 실제 환경 키의 영향으로 5번 수동 키 입력 UI에 접근하지 못했다. [실행 로그](evidence/live-api-2026-10-31/negative-78-first-attempt.log)와 [5번 중단 근거](evidence/live-api-2026-10-31/negative-78-first-attempt/05.json)를 보존했다. 이 시도는 전체 통과로 사용하지 않고 중단 후 격리된 구성으로 처음부터 재실행했다.
