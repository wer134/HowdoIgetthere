# P2 가로 화면 저장 버튼 수정

2026-10-30. 70번의 844×390 가로 화면에서 편집 패널이 화면보다 커져 저장 버튼에 접근할 수 없던 문제를 수정했다. 편집 패널의 최대 높이를 뷰포트에서 상하 여백을 뺀 높이로 제한하고 기존 내부 스크롤을 사용한다.

같은 70번 재현 절차와 판정 조건을 다시 실행했다. 화면 크기 변경 시 입력 유지와 스크롤 후 저장 버튼 접근 모두 통과했다. 패널 높이는 734.25px → 298px, 저장 버튼 y는 702.25px → 266.25px로 바뀌었다. [결과 JSON](evidence/p2-layout/70.json), [가로 화면](evidence/p2-layout/70-landscape.png).

기준 보고서의 증거를 덮어쓰지 않도록 재현 도구에 `NEGATIVE_OUT` 출력 경로 옵션만 추가했다. 실제 기기의 소프트 키보드 검증은 포함하지 않는다.

재현:

```bash
ONLY=70 NEGATIVE_OUT=/tmp/routeflow-70 APP_URL=http://127.0.0.1:8093 node docs/testing/repro/negative-78.cjs
```
