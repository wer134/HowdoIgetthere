# RouteFlow 부정 테스트 78개 수정 후 재검증

2026-10-31 후속 검증: [실제 Google·Gemini 연동 및 재검증](live-api-2026-10-31.md). 아래 기록의 “실제 API 0건”은 당시 실행 범위입니다.

이후 사용자 관점 개선과 최신 전체 재검증은 [사용자 관점 검증 보고서](traveler-readiness.md)를 참조하세요. 아래는 이전 수정 단계의 실행 기록입니다.

대상: `wer134/HowdoIgetthere`, main 기준 `de2ecb4`에서 수정한 로컬 `work` 브랜치 `603ff2f7a503c2c4203b5b870b24b1fcce9fb872`. 실행: 2026-10-30T14:07:05.920Z ~ 2026-10-30T14:11:01.625Z (UTC).

**전체 78개: 통과 70 · 결함 확인 0 · 검증 불가 8. 기존 결함 25개 중 25개가 수정 후 통과했다.** 항목 일부가 미실행이면 전체를 통과로 올리지 않았다. [수정 전 보고서](negative-tests-78-baseline.md)는 45 통과·25 결함·8 검증 불가였으며 원본 증거도 보존했다.

**실제 Google API 호출 검증은 0건이다.** 사용 가능한 Google 키가 없어 외부 네트워크를 차단한 별도 Chromium 프로세스와 항목별 비영속 BrowserContext를 사용했다. 여행 A/B, 파일, API 키는 전용 테스트 데이터다. 실제 사용자 여행이나 브라우저를 사용하지 않았다. 검색·사진·상세·경로는 모의 SDK 응답이고 지도는 MapView 호출 기록 대역이다. 모의 통과는 실제 권한·쿼터·결제·지도 렌더링·장소 품질의 통과가 아니다. 화면의 지도 연결됨 문구도 대역 상태다.

브라우저 Chromium 154.0.8037.57, Playwright 1.62.1, Node 24.19.0. 기본 1440×900, 모바일 대체 390px 및 가로 844×390. 브라우저 시간대는 Asia/Seoul이며 15번에서 별도 변경한다. 동일 항목 내 두 탭만 저장소를 공유한다.
