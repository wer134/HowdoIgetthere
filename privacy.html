데이터 처리 안내

적용 대상: 이 저장소에서 제공하는 RouteFlow 게스트 앱과 선택형 계정 기능. 최종 수정: 2026-11-04. 계정 기능은 운영자가 서버와 인증 서비스를 설정한 설치에서만 제공됩니다.

기기에 저장하는 정보

게스트 여행 일정·후보·메모와 사용자가 저장한 API 키는 현재 브라우저에 저장됩니다. 로그인하지 않고 작성하고 파일로 백업할 수 있습니다. 로그인만으로 기기 여행을 업로드하지 않습니다. 같은 브라우저를 쓰는 사람이 저장된 정보를 열 수 있으므로 공용 기기에서는 사용 후 사이트 데이터를 삭제하세요.

선택형 계정 저장과 공유

계정 서버가 설정된 경우 Google 로그인 식별 정보와 서버 세션을 사용합니다. 사용자가 선택해 계정으로 복사한 여행의 일정·후보·메모를 서버에 저장하며 기기 원본은 유지합니다. 계정 편집의 미전송 임시본은 사용자별 sessionStorage에 저장됩니다. 같은 탭을 새로고침하면 복구할 수 있으나 탭을 닫은 뒤의 보존은 보장하지 않습니다.

공유 링크를 가진 사람은 로그인 없이 공유된 일정·후보·메모를 볼 수 있습니다. 링크를 받은 사람이 다른 사람에게 전달할 수도 있으므로 공개해도 되는 내용을 확인한 뒤 공유하세요. 로그인한 동행자의 장소 제안과 제안자 정보는 여행 주인이 검토할 수 있습니다. 공유 링크는 30일 뒤 만료되며 주인이 갱신하거나 취소할 수 있습니다. 링크 취소는 이미 내려받거나 복사한 내용까지 회수하지 않습니다.

전화 인증과 무료 AI

운영자 비용으로 제공하는 무료 AI가 활성화된 설치에서는 로그인과 최근 전화 인증, 본인 소유 계정 여행이 필요합니다. 문자 인증에는 Twilio Verify를 사용하며 전화번호와 인증 요청이 Twilio에 전송됩니다. 서버에는 전화번호의 암호화 값과 중복·사용량 제한용 식별 해시, 인증 시각 및 사용량 기록을 보관합니다. 남용 방지를 위해 계정·번호·네트워크별 요청을 제한합니다. 전화 인증은 법적 실명 인증이 아닙니다.

수동 편집, 게스트·계정 저장, 개인 API 키 사용에는 전화 인증이 필요하지 않습니다. 무료 AI와 문자 서비스는 기본 비활성화 상태이며 실제 제공 여부와 한도는 설치 설정에 따라 달라집니다.

외부 서비스로 보내는 정보

  • Google Maps·Places·Routes: 지도 표시 정보, 장소 검색어, 좌표, 이동 조건 등 기능에 필요한 정보가 Google로 전송됩니다.
  • 개인 키로 사용하는 AI: 여행 생성 조건을 보냅니다. 하루 수정에서는 선택 날짜의 장소·시간·메모·좌표와 수정 요청을 보냅니다. 인증용 API 키는 해당 제공업체로 전송됩니다.
  • 운영자 무료 AI: 화면에서 요청한 여행 정보와 지시가 서버를 거쳐 설정된 AI 제공업체로 전송됩니다. 운영자 키는 브라우저에 제공하지 않습니다.
  • 환율 조회 시 통화 정보가 api.frankfurter.dev로 전송됩니다. 외부 폰트 사용 시 Google Fonts에 네트워크 요청이 발생합니다. 호스팅 사업자는 일반적인 접속 로그를 처리할 수 있습니다.
  • 외부 제공업체의 보관·처리 정책은 각 제공업체의 약관과 개인정보 정책을 따릅니다.

보관과 삭제

기기 여행은 직접 삭제하거나 브라우저 사이트 데이터를 지울 때까지 남습니다. 설정에서 저장한 키를 비우면 해당 키 사용을 중지할 수 있습니다. 전체 사이트 데이터를 지우기 전에 필요한 여행을 백업하세요. 내려받은 백업·엑셀·일정표는 직접 관리하고 삭제해야 합니다.

로그아웃은 서버 세션을 폐기하고 현재 탭의 계정 편집 임시본을 정리하지만 서버 여행의 삭제를 뜻하지 않습니다. 실제 계정 서비스를 운영하기 전에 운영자가 서버 데이터 보관 기간, 계정·여행 삭제 요청 방법, 비공개 연락처를 확정해 게시해야 합니다. 이 문서만으로 운영 주체나 보관 정책이 확정된 것은 아닙니다.

Google 응답 캐시는 앱에서 만료 처리하며 사진·리뷰는 여행 백업에 포함하지 않습니다. 캐시 보관 가능 범위는 각 Google API 정책에 따라 달라질 수 있습니다.

분석 도구와 민감정보

별도 행동 분석 도구는 설치되어 있지 않습니다. 예약번호·신분증·금융정보 등 민감정보를 AI 요청, 공유 여행이나 공개 문의에 적지 마세요.
