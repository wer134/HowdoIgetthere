데이터 처리 안내

적용 대상: 이 저장소에서 제공하는 RouteFlow 정적 웹앱. 최종 수정: 2026-10-31.

기기에 저장하는 정보

여행 일정, 장소, 메모, 편집 초안, 설정과 사용자가 저장한 API 키는 현재 브라우저의 localStorage에 보관합니다. RouteFlow가 제공하는 계정이나 여행 동기화 서버는 없습니다. 같은 브라우저를 쓰는 사람이 저장된 정보를 열 수 있으므로 공용 기기에서는 사용 후 사이트 데이터를 삭제하세요.

외부 서비스로 보내는 정보

  • Google Maps·Places·Routes: 지도를 사용하거나 장소·경로를 조회할 때 지도 표시 정보, 장소 검색어, 좌표, 이동 조건 등이 Google로 전송됩니다.
  • 선택한 AI 제공업체: 일정 생성 요청을 보냅니다. 하루 수정에서는 선택 날짜의 장소·시간·메모·좌표와 수정 요청을 보냅니다. 다른 날의 일정과 API 키를 요청 본문에 포함하지 않지만 인증용 키는 해당 제공업체로 전송됩니다.
  • 환율 조회를 사용하는 경우 통화 정보가 환율 제공자(api.frankfurter.dev)로 전송됩니다. 외부 폰트를 불러오면 Google Fonts에 네트워크 요청이 발생합니다.
  • 외부 제공업체의 보관·처리 정책은 해당 제공업체의 약관과 개인정보 정책을 따릅니다. 호스팅 사업자는 일반적인 접속 로그를 처리할 수 있습니다.

보관과 삭제

여행은 사용자가 삭제하거나 브라우저 사이트 데이터를 지울 때까지 기기에 남습니다. 설정에서 저장한 키를 비우면 해당 키 사용을 중지할 수 있습니다. 편집 초안·캐시를 포함해 모두 지우려면 브라우저의 이 사이트 데이터 삭제를 사용하세요. 먼저 필요한 여행을 백업해 주세요. 내려받은 백업·엑셀은 사용자가 직접 관리하고 삭제해야 합니다.

Google 응답 캐시는 앱에서 만료 처리하며 사진·리뷰는 여행 백업에 포함하지 않습니다. 캐시 보관 가능 범위는 각 Google API 정책에 따라 달라질 수 있습니다.

분석 도구와 민감정보

현재 배포본에는 GA4 등 별도 행동 분석 도구가 설치돼 있지 않습니다. 예약번호·신분증·금융정보 등 민감정보를 AI 요청이나 공개 문의에 적지 마세요.

프로젝트 관리·문의: RouteFlow GitHub Issues. 문의는 공개되므로 API 키와 개인 여행 내용은 제외하세요.
