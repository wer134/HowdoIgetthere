    구글 지도 API 키

    키는 이 브라우저에만 저장돼요. 지우려면 칸을 비우고 저장하세요.

    1. Google Cloud 콘솔에서 프로젝트를 만들고 결제 계정을 연결
    2. Maps JavaScript API, Places API (New), Routes API 사용 설정
    3. 사용자 인증 정보 → API 키 만들기 → 위 칸에 붙여 넣기

    Claude API 키 일정 추천 · 선택

    넣으면 Claude가 도시 배분·동선·교통 패스까지 고려해 일정을 짜요. 없으면 구글 지도 데이터만으로 짜요.

    1. Anthropic 콘솔에서 API 키를 만들고 크레딧을 충전 (Claude 구독과는 따로예요)
    2. 콘솔의 Limits에서 월 사용 한도를 걸어 두세요. 일정 하나에 약 $0.2~0.3이 들어요
    3. 키는 이 브라우저에만 저장되고, 이 브라우저에서 Claude로 바로 보내요. 공용 PC에서는 넣지 마세요

    저장된 결과

    엑셀 양식

    평소 쓰는 여행 일정표에 장소 열 하나만 더하면 돼요. 장소가 빈 행(이동·휴식)은 지도에 나오지 않아요.

    • 장소 칸에는 이름만: “쿠시다 신사 참배”가 아니라 “쿠시다 신사”
    • “호텔”, “숙소” 대신 실제 이름을 적어요
    • 한 칸에 한 곳만. 두 곳이면 행을 나눠요
    • 해외 장소를 못 찾으면 현지어 이름으로 (예: 櫛田神社)

    동선

    날짜·시간·이동 수단 열이 있으면 같은 날의 장소를 순서대로 잇고, “경로 찾기”로 구간마다 실제 경로와 시간을 찾아요. 구간을 누르면 노선·정거장·출발 시각과 구글 지도 길찾기 링크가 나와요.

    일정 점검

    경로를 찾으면 일정표에 잡은 이동 시간이 구글 경로보다 모자란 구간을 알려 줘요. 구간을 눌러 앞 일정 줄이기나 뒤 일정 미루기를 고르면 시간 칸이 바뀌고, 고친 일정 엑셀로 저장을 누르면 원래 파일에서 그 칸만 바꾼 사본을 내려받아요. 메모 등에 [고정]이라고 적은 행(항공·예약)은 바꾸지 않아요.

    여유 정도(빠듯하게·보통·여유롭게)를 고르면 구글 소요 시간에 걷는 시간·탈 때마다·짐 들고 움직일 때의 여유를 더해 판단해요. 이동 행에 [짐]이라고 적으면 짐을 들고 움직이는 구간으로 봐요.

    놓치면 오래 기다리는 차(특급·공항버스·셔틀, 첫차·막차, [고정])는 타기 전 앞 일정과 여유가 있는지 봐요. 배차는 메모의 “시간당 4~5대”, “30분 간격” 같은 말을 먼저 읽고, 없으면 이동 수단 글자로 짐작해요.

    여행 일정 추천

    나라·지역, 날짜, 관심사를 넣고 일정 짜기를 누르면 일정표를 만들어 지도에 바로 올려요. 그다음은 엑셀을 올렸을 때와 같아요: 경로 찾기, 일정 점검, 하루 예산, 빈 끼니의 맛집 추천.

    설정에 Claude API 키가 있으면 Claude가 도시를 나누고 동선·시각·교통편·입장료를 짜고, 앱이 장소마다 구글 지도에서 찾아 위치와 그날 영업 여부를 확인해요. 걸린 곳은 Claude에게 고쳐 달라고 하기로 다시 받을 수 있어요. 키가 없으면 그 지역에서 구글 평점이 높은 곳을 가까운 곳끼리 날짜별로 묶어요(도시 하나에 맞아요).

    주변 명소·맛집

    일정의 장소를 누르고 주변 맛집·주변 명소를 고르거나, 위 칸에 대표 장소를 적으면 걸어갈 만한 곳을 구글 평점·리뷰 수로 순위를 매겨 보여 줘요. 리뷰가 적은 곳의 높은 평점은 주변 평균 쪽으로 낮춰 보고, 일정 시각에 문을 닫는 곳과 예산을 넘는 곳은 뒤로 보내요.

    일본은 타베로그, 한국은 카카오맵 링크를 함께 달아요. 두 곳은 점수를 가져다 쓸 수 있는 공개 API가 없고 약관도 막고 있어, 링크로 열어 확인한 점수를 옆 칸에 적으면 순위에 반영해요(이 브라우저에만 저장).

    가게를 누르면 사진·한 줄 소개·특징(예약·포장·현금만 등)·리뷰·요일별 영업시간·전화가 펼쳐져요. 한국어로 쓴 리뷰를 먼저 보여 줘요.

    하루 예산

    메모에 적은 금액(“1,800엔”, “1만 5천원”)을 먼저 쓰고, 금액이 없는 끼니·교통·코인로커는 어림해 날짜별로 더해요. 숙박·항공은 빼요. “+2,200엔”, “별도”는 선택 비용, “대안:” 뒤의 금액은 다른 선택지로 보고 더하지 않아요.

    교통비는 구글 경로에 요금이 있으면 그 값을, 없으면 이동 수단과 일정표의 이동 시간으로 어림해요(일본은 구글이 대중교통 경로를 주지 않아 모두 어림). 금액을 눌러 고칠 수 있고, 빈 끼니의 맛집 추천에서 가게를 고르면 그 행의 장소 칸에 넣어 엑셀로 저장할 수 있어요.
